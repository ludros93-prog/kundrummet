# Kundrummet

Privat granskningsrepo för ChatGPT och Claude, baserat på Kundrummet version 28.

- Läs CLAUDE.md för uppdrag, avgränsning och aktuella fel.
- Kundrummet_Claude_granskning_v28.md innehåller hela granskningspaketet och 57 källfiler.
- kundrummet-kod-v28.zip innehåller samma kod som separata filer med ursprungliga sökvägar.

Detta är en granskningsexport, inte ett komplett körbart repository. Binära resurser, tredjepartsbibliotek och deploy-konfiguration ingår inte. Inga kundposter, mötesutkast, lösenord eller tokens ingår.

Ändringar i detta repo publiceras inte automatiskt i appen. ChatGPT granskar och testar förslag före publicering. Inga andra projekt ingår.
